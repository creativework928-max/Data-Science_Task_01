# Titanic Survival Classification
## End-to-End Machine Learning Project

---

## 1. Executive Summary

This project develops a binary classification system that predicts
whether a Titanic passenger survived the sinking.

The project combines exploratory data analysis, statistical analysis,
feature engineering, machine learning model comparison, evaluation,
interpretability and prediction generation.

The primary target variable is:

Survived

where:

0 = Did not survive
1 = Survived

---

## 2. Business / Analytical Objective

The objective is to determine whether passenger characteristics can
be used to predict survival and identify which factors were most
strongly associated with survival.

The analysis focuses particularly on:

- Gender
- Age
- Passenger class
- Fare
- Family relationships
- Cabin information
- Embarkation port

---

## 3. Dataset

The project uses the official Kaggle Titanic Machine Learning from
Disaster dataset.

Training data contains passenger characteristics and the known
survival outcome.

Testing data contains passenger characteristics without the target.

---

## 4. Data Preparation

The following data preparation steps were performed:

- Missing numerical values were imputed using median values.
- Missing categorical values were imputed using the most frequent value.
- Categorical variables were one-hot encoded.
- Numerical variables were standardized where appropriate.
- Passenger names were converted into title features.
- Family size was calculated.
- Individual passenger status was derived.
- Ticket group size was calculated.
- Fare per passenger was calculated.
- Cabin deck was extracted.
- Cabin availability was converted into an indicator.
- Age groups were created.

---

## 5. Exploratory Data Analysis

The analysis investigates:

1. Overall survival distribution
2. Gender and survival
3. Passenger class and survival
4. Gender combined with passenger class
5. Age and survival
6. Fare and survival
7. Family size and survival
8. Embarkation and survival
9. Numerical correlations

---

## 6. Machine Learning

Several classification algorithms were evaluated:

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- HistGradientBoosting

Five-fold stratified cross-validation was used to compare models.

The evaluation metrics were:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

---

## 7. Model Selection

The final model was selected using cross-validation performance,
with ROC-AUC used as the primary comparison metric.

The final model was then retrained using the complete labeled
training dataset.

## 9. Key Findings

The analysis should specifically discuss:

### Gender

Compare survival rates between male and female passengers.

### Socio-economic status

Passenger class is a major analytical factor because Pclass acts
as a proxy for socio-economic status.

### Age

Evaluate survival differences across age groups.

### Family size

Investigate whether traveling alone or with family was associated
with survival.

### Fare

Evaluate whether fare level was associated with survival after
considering passenger class.

### Combined effects

The most important analysis should consider interactions between
gender, passenger class and age rather than examining each factor
in isolation.

---

## 10. Limitations

This dataset represents historical observations rather than a
controlled experiment.

Therefore, model associations should not be interpreted as proof
that a particular characteristic caused survival.

The model predicts patterns observed in the available data.

Missing values and limited sample size can also affect estimates.

---

## 11. Conclusion

The Titanic survival problem demonstrates how demographic,
socio-economic and travel-related variables can be used in a
binary classification system.

Gender, passenger class, age, family circumstances and fare-related
variables should be evaluated jointly.
