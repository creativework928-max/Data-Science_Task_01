# 🚢 Titanic Survival Classification

An end-to-end machine learning project for predicting Titanic
passenger survival.

## Objective

Predict whether a passenger survived the Titanic sinking and
identify the passenger characteristics most strongly associated
with survival.

## Main Factors

- Gender
- Age
- Passenger class
- Fare
- Family size
- Cabin information
- Embarkation
- Passenger title
- Ticket group
